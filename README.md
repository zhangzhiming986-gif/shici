# Shici - GitHub Pages

Upload the extracted files to a PUBLIC repository. Keep index.html in the repository root.

Open Settings > Pages > Build and deployment. Choose Deploy from a branch, then main and /(root), and Save.

Use the URL shown by GitHub Pages after deployment completes. No build step, paid domain, or application login is required.

Words, study progress and daily goals stay in the current browser. They are not committed to this repository. Use the app backup export/import to move data between domains.

Availability depends on the network. Verify the published URL on the intended iPhone before relying on it.
